## Датасет

[**Enron Email Dataset**](https://www.kaggle.com/datasets/wcukierski/enron-email-dataset): около 517 тыс. писем примерно 150 сотрудников (в основном топ-менеджмента) компании Enron за 2000–2002 годы. Корпус был опубликован в ходе расследования FERC и стал одним из стандартных корпусов реальной деловой переписки.

| Параметр | Значение |
|----------|----------|
| Файл | `emails.csv` (~1,4 ГБ) |
| Колонки | `file` — путь письма в ящике (`allen-p/_sent_mail/1.`), `message` — сырое письмо с SMTP-заголовками |
| Язык | английский |
| Разметка | отсутствует; в лабораторной №1 класс выводится из папки (`sent`, `inbox`, `deleted`, пользовательские папки, автоархивы Lotus Notes) |

Особенности, которые важно учитывать:
- **Много дублей.** Одно письмо лежит у отправителя, у получателей и в автоархивах (`all_documents`, `discussion_threads`). Дедуплицировать нужно до разбиения на train/test.
- **Цитирование и пересылки.** Ответы содержат историю переписки (`-----Original Message-----`, `Forwarded by`), то есть чужой текст.
- **Технический шум:** адреса Lotus Notes (`Name/HOU/ECT@ECT`), артефакты quoted-printable (`=20`), HTML.

## Запуск

```bash
git clone <repo-url> && cd itmo-text-analysis
python -m venv .venv && source .venv/bin/activate

# датасет: скачать архив с Kaggle вручную или через Kaggle CLI (нужен ~/.kaggle/kaggle.json)
pip install kaggle
kaggle datasets download -d wcukierski/enron-email-dataset -p labs/lab1/data --unzip

cd labs/lab1
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```

Датасет не хранится в репозитории: папки `data/` исключены в `.gitignore`. Для воспроизводимости во всех работах зафиксирован `SEED = 42`.
